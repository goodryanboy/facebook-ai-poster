Privacy Policy

Last updated: August 2, 2026

This privacy policy describes how this application ("the App") handles data. The App is a personal automation tool that generates images and publishes them to a Facebook Page that the developer owns and administers.

What the App does

The App automatically generates images and posts them to a single Facebook Page controlled by the developer. It runs on a fixed schedule with no user interaction and does not provide any public-facing login, sign-up, or user account system.

Data the App accesses

The App uses the Facebook Graph API with a Page Access Token to publish content on the developer's own Facebook Page. Specifically, it accesses:

  • The Page ID and Page Access Token needed to publish posts
  • Standard API response data (e.g. post ID, publish status) returned after a post is created, used only for logging and error-checking

The App does not collect, request, or process personal data from Facebook users, Page followers, or any third party. It does not read comments, messages, follower lists, or any user-level data. It does not use tracking pixels, cookies, or analytics on any external site.

Data storage

The Page Access Token is stored as an encrypted secret within the developer's private automation environment (GitHub Actions secrets) and is not shared with, sold to, or accessible by any third party. No other data is stored outside of this token and standard application logs used for debugging.

Data sharing

The App does not share, sell, rent, or transfer any data to third parties. All activity is limited to publishing content to the developer's own Facebook Page via the official Facebook Graph API.

Data retention and deletion

No user data is collected, so there is no user data to retain or delete. Should the developer choose to discontinue the App, the associated Page Access Token will be revoked and deleted from all storage locations.

Changes to this policy

This policy may be updated periodically to reflect changes in the App's functionality. The "Last updated" date above will reflect the most recent revision.
